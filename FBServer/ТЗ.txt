Измени страницу управления скриптами. На ней должна быть кнопка "Добавить скрипт" при нажатии на которую должны открываться форма в которую можно ввести: "Название", "IP адрес", "Порт".
При нажатии кнопки "Добавить" должен отправляться http post запрос по адресу http://localhost:5253/Script в теле которого должен быть JSON формата 
{
  "name": "string",
  "ip": "string",
  "port": 0
}

При открытии страницы должен отправляться http get запрос по адресу http://localhost:5253/Script в ответ придет JSON коллекция формата 
[
  {
    "id": 1,
    "name": "test",
    "ip": "127.0.0.1",
    "port": 5000
  },
  {
    "id": 2,
    "name": "test 2",
    "ip": "127.0.0.1",
    "port": 5001
  }
]
Это набор скриптов. Необходимо чтобы они отображались на странице, напротив каждого скрипта должны быть кнопки старт/стоп и проверка статуса.
При нажатии на кнопку старт должна открываться форма с вводом url и глубиной (число) при нажатии на форме старт отправляться http post запрос по адресу http://localhost:5253/Script/start?id= (id = id выбранного скрипта) с телом вида
{
  "link": "string",
  "depth": 0
}

При нажатии на кнопку стоп отправляется http get запрос по адресу http://localhost:5253/Script/stop
При нажатии на кнопку проверки статуса отправляется http get запрос по адресу http://localhost:5253/Script/status?id= (id = id выбранного скрипта). В ответ придет JSON формата
{
  "link": "string",
  "started": true
}

Если скрипт запущен, то у него должен отображаться статус активнй и написана текущая ссылка, если "started": false, то отображаться статус не активен
